# 🐱 SafePet Food - Cat Food Ingredient Analyzer

SafePet es una aplicación web y móvil ligera impulsada por Inteligencia Artificial (Google Gemini Visión) que analiza las etiquetas e ingredientes del alimento para gatos en tiempo real a través de la cámara del dispositivo.

## 🚀 Características
- 📸 **Captura con cámara integrada:** Toma fotos directamente a las etiquetas de comida.
- 🧬 **Análisis mediante IA:** Lee el texto de la imagen e identifica proteínas, granos, conservantes y aditivos.
- 📊 **Calificación Nutricional:** Evalúa la calidad del producto y advierte sobre ingredientes potencialmente perjudiciales para los felinos.
